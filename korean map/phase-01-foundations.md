# LEVEL 0 — HANGEUL AND THE SOUND SYSTEM

> **Goal.** Read any Korean text aloud correctly — including words you have never seen — with all seven sound-change rules applied without conscious thought. Then produce the sounds well enough that a native speaker does not have to work to understand you.

## 0.1 — Why Hangeul is a design problem, not a memorisation problem

**Objective.** Understand the logic of the script so that 24 letters take hours instead of weeks.

### Module 0.1.1 — The featural principle

- [ ] Every consonant shape encodes where the sound is made: `ㄱ` the tongue rising at the back; `ㄴ` the tongue at the ridge; `ㅁ` the shape of a mouth; `ㅅ` the shape of teeth; `ㅇ` the throat, empty.
- [ ] Consonants come in families — plain, aspirated, tensed — and the aspiration is drawn *as an extra stroke*: `ㄱ` → `ㅋ`, `ㄷ` → `ㅌ`, `ㅂ` → `ㅍ`, `ㅈ` → `ㅊ`.
- [ ] Vowels are built from three elements: a dot (sky, ㅗ/ㅏ), a horizontal line (earth, ㅡ), a vertical line (human, ㅣ). Every compound vowel is a combination.
- [ ] There are no capitals, no cursive, and no positional letter variants.

> This is why the script is learnable in days. It is one of the few writing systems in the world that a literate adult can acquire analytically rather than by rote.

### Module 0.1.2 — What Hangeul does *not* tell you

- [ ] It is phonemic, not phonetic: it spells the *morpheme*, not the sound. `꽃이` is written with ㅊ and pronounced [꼬치].
- [ ] Sound changes are unwritten. The gap between spelling and speech is the whole difficulty of Korean listening.
- [ ] Spacing (띄어쓰기) carries grammatical information and is a separate skill (L6).

> **Module completion gate (0.1).** You can explain, in two sentences, why Hangeul is fast to learn and why that does not make Korean fast to learn.

## 0.2 — The nineteen consonants

**Objective.** Produce all nineteen, and hear the three-way distinction that English lacks.

### Module 0.2.1 — The fourteen basic consonants

| Letter | Sound | Description |
|---|---|---|
| ㄱ | unaspirated k/g | between English *g* and *k*; no puff of air |
| ㄴ | n | as in *no* |
| ㄷ | unaspirated t/d | between *d* and *t* |
| ㄹ | tapped r / l | Spanish *pero* between vowels; *l* as a final |
| ㅁ | m | |
| ㅂ | unaspirated p/b | between *b* and *p* |
| ㅅ | s | *sh* before ㅣ and ㅑ/ㅕ/ㅛ/ㅠ |
| ㅇ | silent initially; *ng* finally | a placeholder at the start of a syllable |
| ㅈ | unaspirated ch/j | |
| ㅊ | aspirated ch | with a puff |
| ㅋ | aspirated k | with a puff |
| ㅌ | aspirated t | with a puff |
| ㅍ | aspirated p | with a puff |
| ㅎ | h | |

### Module 0.2.2 — The five tense consonants

| Letter | Sound | Production note |
|---|---|---|
| ㄲ | tense k | throat tight, no air |
| ㄸ | tense t | |
| ㅃ | tense p | |
| ㅆ | tense s | hissy, sustained |
| ㅉ | tense j | |

### Module 0.2.3 — The three-way stop distinction

- [ ] English has a two-way distinction (voiced/voiceless). Korean has three: **plain** (ㄱ), **aspirated** (ㅋ), **tensed** (ㄲ).
- [ ] Say the triplet `가 / 카 / 까` until a native speaker or a recording confirms all three are distinct.
- [ ] Do not rely on voicing ([g] vs [k]) — Korean's plain series is voiced between vowels and voiceless elsewhere, which is not a distinction English ears track.
- [ ] Hold a sheet of paper in front of your mouth: ㅋ and ㅌ should move it, ㄱ and ㄲ should not, and ㄲ should feel tighter in the throat than ㄱ.

> **Why this matters now.** If you cannot distinguish these three at the start, you cannot hear them later — and Korean is full of minimal pairs that depend on them: `불` fire / `풀` grass / `뿔` horn.

> **Module completion gate (0.2).** You produce all nineteen consonants on demand from a random order, and a recording of yourself saying 가/카/까, 다/타/따, 바/파/빠 is audibly three-way different.

## 0.3 — The twenty-one vowels

**Objective.** Produce ten basic and eleven compound vowels without collapsing ㅓ/ㅗ or ㅡ/ㅜ.

### Module 0.3.1 — The ten basic vowels

| Letter | Sound | Anchor |
|---|---|---|

| ㅑ | ya | *yard* |
| ㅓ | eo | *uh*, mouth open, tongue back — **not** *oh* |
| ㅕ | yeo | *yuh* |
| ㅗ | o | *go*, rounded |
| ㅛ | yo | |
| ㅜ | u | *boot*, short |
| ㅠ | yu | |
| ㅡ | eu | teeth together, lips flat, a grunt — **not** *oo* |
| ㅣ | i | *see*, short |

### Module 0.3.2 — The eleven compound vowels

| Letter | Sound | Note |
|---|---|---|
| ㅐ | ae | *bed*, open |
| ㅒ | yae | rare |
| ㅔ | e | *bed*, shorter; merged with ㅐ for most speakers under 50 |
| ㅖ | ye | |
| ㅘ | wa | |
| ㅙ | wae | |
| ㅚ | oe | *way* in modern Seoul speech |
| ㅝ | wo | |
| ㅞ | we | |
| ㅟ | wi | |
| ㅢ | ui | glide; as the possessive particle it is pronounced 에 |

### Module 0.3.3 — The two collapses to fix now

- [ ] **ㅓ vs ㅗ.** English speakers round ㅓ into ㅗ. Say pairs: 어-오, 어-오. Then `언어` (language) — it must not become 오노.
- [ ] **ㅡ vs ㅜ.** ㅡ is unrounded; ㅜ is rounded. Say pairs: 크-쿠, 크-쿠. Then `그` (that) versus `구` (nine).
- [ ] Record both pairs and listen back with headphones. This self-check catches what your ear will not.

> **Module completion gate (0.3).** You read the full vowel chart from memory, and your recording of 어/오 and 크/쿠 is distinguishable by a native speaker or by a language-exchange partner.

## 0.4 — Syllable blocks and writing

**Objective.** Build and handwrite any syllable.

### Module 0.4.1 — Block structure

- [ ] Every syllable is `(initial consonant) + vowel + (final consonant)`.
- [ ] Six shapes: `가` (C+V), `강` (C+V+C), `과` (C+V+V), `아` (ㅇ+V), `안` (ㅇ+V+C), `완` (C+V+V+C).
- [ ] ㅇ is silent in the initial position and *ng* in the final position.
- [ ] Stroke order: top-left first, then right, then bottom. Learn it once, correctly.

### Module 0.4.2 — Handwriting

- [ ] Write each of the 40 letters ten times, saying the sound aloud.
- [ ] Write your own name in Hangeul, then a Koreanised version of three friends' names.
- [ ] Write ten words from dictation given by a text-to-speech voice.

> **Module completion gate (0.4).** You handwrite 20 random syllables from dictation with correct block construction and legible stroke order.

## 0.5 — Batchim and the seven-sound rule

**Objective.** Understand why written Korean has 27 final consonants and spoken Korean has seven.

### Module 0.5.1 — The collapse

| Spoken as | Written letters that collapse into it | Example |
|---|---|---|
| **ㄱ** [k] | ㄱ ㄲ ㅋ ㄳ ㄺ | 국 [국], 밖 [박], 부엌 [부억] |
| **ㄴ** [n] | ㄴ ㄵ ㄶ | 눈 [눈], 앉다 [안따] |
| **ㄷ** [t] | ㄷ ㅅ ㅆ ㅈ ㅊ ㅌ ㅎ | 옷 [옫], 꽃 [꼳], 낮 [낟], 있다 [읻따] |
| **ㄹ** [l] | ㄹ ㄼ ㄽ ㄾ ㅀ | 말 [말], 여덟 [여덜] |
| **ㅁ** [m] | ㅁ ㄻ | 밤 [밤], 삶 [삼] |
| **ㅂ** [p] | ㅂ ㅍ ㅄ ㄿ | 밥 [밥], 앞 [압], 값 [갑] |
| **ㅇ** [ng] | ㅇ | 강 [강] |

### Module 0.5.2 — Double batchim: one survives

- [ ] ㄺ → ㄱ before a consonant: 읽다 [익따], 맑다 [막따], 닭 [닥]
- [ ] ㄻ → ㅁ: 삶 [삼]
- [ ] ㄼ → ㄹ: 여덟 [여덜], 넓다 [널따]
- [ ] ㅄ → ㅂ: 값 [갑], 없어요 [업써요]
- [ ] ㄵ → ㄴ: 앉아요 [안자요]
- [ ] ㄶ → ㄴ, with the ㅎ dropped: 많아요 [마나요]

### Module 0.5.3 — Unreleased finals

- [ ] A final stop (ㄱ/ㄷ/ㅂ) is never released in Korean — no puff of air at the end. `밥` ends with the lips closed, not with a *p*.
- [ ] This is the single most audible marker of a foreign accent. Practise stopping the sound in your mouth.

> **Module completion gate (0.5).** Given any batchim word, you state its seven-sound collapse without a reference, and your recording of 밥/밤/밥 does not release the final.

## 0.6 — The seven sound-change rules

**Objective.** Turn written Korean into spoken Korean. This section is the reason your reading will sound human.

### Module 0.6.1 — Liaison (연음): the final moves forward

$$\text{C}_{\text{final}} + \varnothing_{\text{onset}} \;\longrightarrow\; \varnothing_{\text{final}} + \text{C}_{\text{onset}}$$

| Written | Spoken | Meaning |
|---|---|---|
| 한국어 | [한구거] | Korean language |
| 음악 | [으막] | music |
| 옷이 | [오시] | clothes (subject) |
| 이름은 | [이르믄] | name (topic) |
| 먹어요 | [머거요] | eats |
| 좋아요 | [조아요] | good |

- [ ] This is the most frequent rule in the language. At normal speed, words bleed into each other constantly.
- [ ] Drill: read 30 two-syllable words where the second begins with ㅇ, applying liaison every time.

### Module 0.6.2 — Aspiration (격음화): ㅎ fuses with a stop

| Combination | Becomes | Example |
|---|---|---|
| ㄱ + ㅎ / ㅎ + ㄱ | ㅋ | 놓고 [노코], 축하 [추카] |
| ㄷ + ㅎ | ㅌ | 좋다 [조타], 맏형 [마텽] |
| ㅂ + ㅎ | ㅍ | 잡히다 [자피다] |
| ㅈ + ㅎ | ㅊ | 앉히다 [안치다] |

### Module 0.6.3 — Tensification (경음화): after a stop batchim

ㄱ/ㄷ/ㅂ + ㄱ/ㄷ/ㅂ/ㅅ/ㅈ → tensed.

| Written | Spoken | Meaning |
|---|---|---|
| 학교 | [학꾜] | school |
| 먹다 | [먹따] | to eat |
| 잡지 | [잡찌] | magazine |
| 국밥 | [국빱] | rice in soup |
| 있다 | [읻따] | to exist |
| 식당 | [식땅] | restaurant |

### Module 0.6.4 — Nasalisation (비음화): stop + nasal

ㄱ/ㄷ/ㅂ + ㄴ/ㅁ → ㅇ/ㄴ/ㅁ.

| Written | Spoken | Meaning |
|---|---|---|
| 국물 | [궁물] | broth |
| 닫는 | [단는] | closing |
| 밥물 | [밤물] | rice water |
| 한국말 | [한궁말] | Korean speech |
| 십만 | [심만] | one hundred thousand |
| 있습니다 | [이씀니다] | there is |

### Module 0.6.5 — Liquidisation (유음화): ㄴ and ㄹ

ㄴ + ㄹ or ㄹ + ㄴ → [ㄹㄹ].

| Written | Spoken | Meaning |
|---|---|---|
| 신라 | [실라] | Silla |
| 연락 | [열락] | contact |
| 한류 | [할류] | Korean wave |
| 물냉면 | [물랭면] | cold noodles in broth |
| 설날 | [설랄] | Lunar New Year |

### Module 0.6.6 — Palatalisation (구개음화): ㄷ/ㅌ before 이

| Written | Spoken | Meaning |
|---|---|---|
| 같이 | [가치] | together |
| 굳이 | [구지] | stubbornly |
| 밭이 | [바치] | field (subject) |
| 붙이다 | [부치다] | to attach |
| 해돋이 | [해도지] | sunrise |

### Module 0.6.7 — ㅎ deletion

| Written | Spoken | Meaning |
|---|---|---|
| 싫어요 | [시러요] | I don't like it |
| 귀찮아요 | [귀차나요] | it's bothersome |
| 괜찮아요 | [괜차나요] | it's fine |
| 않아요 | [아나요] | does not |
| 전화 | [저놔] | telephone |
| 은행 | [으냉] | bank |

> **The sentence that identifies a beginner.** `괜찮아요` said as *gwaen-chan-a-yo*, with a full ㅎ, is understood — and immediately placed. Say [괜차나요]. Record yourself until it sounds like one word, not four syllables.

> **Module completion gate (0.6).** You read 20 unseen words containing sound changes, state which rule applies to each, and your spoken version matches the rule. You can list all seven rules from memory.

## 0.7 — Prosody: rhythm, pitch, and intonation

**Objective.** Stop sounding like a sequence of syllables. Korean has no stress accent, so learners who import English stress sound wrong even when every phoneme is correct.

### Module 0.7.1 — Syllable timing

- [ ] Korean is syllable-timed, not stress-timed. Every syllable gets roughly equal duration; do not crush unstressed syllables the way English does.
- [ ] Consequence: Korean speech sounds *flatter and faster* than English to a learner, and your English rhythm sounds *lumpy* to a Korean.

### Module 0.7.2 — Pitch

- [ ] Korean uses pitch at the phrase level, not the word level: a rise at the end of a question, a fall at the end of a statement.
- [ ] Long vowels carry emotional weight: `네~` (yes, drawn out) signals hesitation or disbelief.
- [ ] There is no lexical tone — pitch does not change word meaning, but it changes *attitude*, which is where misunderstanding lives.

### Module 0.7.3 — Intonation contours to copy

| Function | Contour | Example |
|---|---|---|
| Statement | level then slight fall | 갔어요. |
| Yes/no question | rise at the end | 갔어요? |
| Wh-question | rise then fall | 어디 갔어요? |
| Surprise | high rise | 정말요? |
| Listing | slight rise on each, fall on last | 사과, 배, 감. |

> **Module completion gate (0.7).** You shadow a 60-second native clip and your recording has the same contour shape — checked visually on a pitch track or by comparing lengths of matched phrases.

## 0.8 — Reading fluency

**Objective.** Convert decoding into reading. Accuracy first, then speed.

### Module 0.8.1 — Measurement

$$\text{syllables per minute} = \frac{\text{syllables read}}{\text{seconds}} \times 60$$

- [ ] Take a 100-syllable passage, read aloud, time it, divide.
- [ ] Count errors separately. A fast read with wrong sound rules is not progress.

| Stage | Speed target | Accuracy target |
|---|---|---|
| End of 0.4 | 20 syl/min | 90% |
| End of 0.6 | 40 syl/min | 95% |
| End of L0 | 60 syl/min | 98% |
| L6 | 80 syl/min | 99% |
| L12 | 110 syl/min | 99% |
| L16 | 130+ syl/min | 99% |

### Module 0.8.2 — What to read

- [ ] Start with syllable charts, then word lists, then short sentences, then a paragraph of a children's book.
- [ ] Read *novel* text every session — re-reading the same passage inflates speed without building decoding.
- [ ] Read aloud, always. Silent reading at this stage trains nothing.

> **Module completion gate (0.8).** 60 syllables per minute on unseen text at 98% rule accuracy, measured three days in a row.

## 0.9 — Listening for phonemes

**Objective.** Build the perceptual categories that reading cannot build. This module is why your pronunciation will improve without a tutor in this level.

### Module 0.9.1 — Minimal-pair discrimination

| Pair | Contrast |
|---|---|
| 가 / 카 / 까 | plain / aspirated / tensed |
| 다 / 타 / 따 | |
| 바 / 파 / 빠 | |
| 자 / 차 / 짜 | |
| 살 / 쌀 | plain / tensed s |
| 어 / 오 | vowel collapse |
| 크 / 쿠 | unrounded / rounded |
| 눈 / 눋 | none — both [눈]; a spelling lesson |

### Module 0.9.2 — Dictation as a test of perception

- [ ] Dictate 20 words per session from an audio source, in Hangeul.
- [ ] Mark every miss. Group the misses: was it a consonant, a vowel, a batchim, or a sound rule?
- [ ] The group with the most misses is your training target for the next session.

### Module 0.9.3 — The three-pass method

- [ ] Pass 1 blind; pass 2 sentence-by-sentence dictation; pass 3 compare and mark.
- [ ] Re-listen to the missed spots immediately, three times, before moving on.

> **Module completion gate (0.9).** 20-word dictation at 95% accuracy, with misses classified by cause rather than simply corrected.

## 0.10 — Level 0 Capstone: `sound-lab`

**Objective.** Produce a recorded, reviewable corpus that proves the level's outcome — not a claim that you "know the alphabet".

### A. Functional requirements

1. **The alphabet corpus.** You record all 40 letters, isolated, in a single take, with no reading from a list you can see mid-recording.
2. **The minimal-pair corpus.** Ten triplets (가/카/까 and nine others) recorded twice, with a 2-second gap.
3. **The sound-rule corpus.** Twenty sentences, each containing at least one sound-change rule, recorded at natural speed.
4. **The reading corpus.** Three unseen passages of 100+ syllables, read aloud, timed, with the time and syllable count written down.
5. **The dictation log.** Ten sessions of 20 words, with accuracy per session and a running list of your recurring phoneme errors.
6. **The self-assessment.** One paragraph, written, naming your three weakest sounds and the drill you used for each.

### B. Suggested architecture

```

│
├── 01_alphabet/            ← 40 isolated letters, one take
│   └── alphabet.wav
│
├── 02_minimal_pairs/       ← triplets, twice each

│
├── 03_rules/               ← 20 sentences, natural speed
│   ├── liaison.txt         ← the sentence, the rule, the expected IPA-ish gloss

│   ├── nasalisation.txt
│   └── rules.wav
│
├── 04_reading/             ← three unseen passages + timings
│   ├── passage_1.txt
│   ├── record_1.wav
│   └── timings.md
│
├── 05_dictation/           ← ten sessions, accuracy per session
│   └── log.md
│
└── 06_review/
    ├── self_assessment.md  ← three weakest sounds + the drills used
    └── reviewer_notes.md   ← filled by a tutor or exchange partner
```

### C. Suggested folder discipline

| File | Must contain |
|---|---|
| `timings.md` | date, passage length, seconds, syllables/min, error count |
| `log.md` | session number, source clip, accuracy, error category |
| `self_assessment.md` | three specific weaknesses, not "pronunciation" |
| `reviewer_notes.md` | one sentence per corpus item from a native or advanced speaker |

### D. Acceptance targets

| Dimension | Target |
|---|---|
| Reading speed | ≥ 60 syllables/minute on unseen text |
| Rule accuracy | ≥ 98% on 50 randomly sampled syllables |
| Covering all rules | at least one example of each of the seven rules in the corpus |
| Dictation | ≥ 95% over the last three sessions |
| Native intelligibility | a native speaker transcribes 18 of 20 rule sentences correctly |
| Self-assessment honesty | names three specific phonemes, not generalities |

### E. Stretch goals

- Record the corpus a second time on a different day and compare — consistency is the real test.
- Read a nursery rhyme or a poem aloud with correct rhythm, not just correct phonemes.
- Have a native speaker produce the same minimal-pair corpus and compare yours side by side.

| Requirement | Weight | Pass condition | Evidence |

## Level 0 question bank

### Group A — Reading and orthography

1. Read aloud: `안녕하세요. 저는 인도 사람입니다.`

## 1.1 — How a Korean sentence is built

**Objective.** Internalise the shape of the language before learning vocabulary.

### Module 1.1.1 — Verb-final order

- [ ] The verb is always last. `저는 밥을 먹어요.` — *I rice eat.*
- [ ] Everything else can move, because particles mark the role, not the position.
- [ ] Modifiers come before what they modify: `맛있는 밥` — *delicious rice*.
- [ ] Consequence for English speakers: you must hold the sentence open until the end. Practise by starting with the verb in mind.

### Module 1.1.2 — Particles, not word order

| Particle | Function | Example |
|---|---|---|
| 은/는 | topic | 저는 |
| 이/가 | subject | 비가 와요 |
| 을/를 | object | 밥을 |
| 에 | time, destination | 세 시에, 학교에 |

- [ ] Particles attach directly, with no space: `밥을`, not `밥 을`.
- [ ] Particles can be dropped in speech and are *never* dropped in formal writing.

### Module 1.1.3 — The two polite registers you need first

| Register | Form | Use |
|---|---|---|
| **해요체** | verb + -아/어요 | the daily default, polite but not stiff |
| **합니다체** | verb + -ㅂ니다/습니다 | presentations, news, first meetings, the military, the elderly |

- [ ] Learn both now. Using only 해요체 is fine; being unable to switch to 합니다체 is a ceiling.

> **Module completion gate (1.1).** You build ten sentences by putting the verb last, and you can explain which particle marks the object, the topic, and the subject.

## 1.2 — The copula and the two "to be"s

**Objective.** Say "is" and "is not" correctly — the first thing every conversation needs.

### Module 1.2.1 — 이다

| Form | After a consonant | After a vowel |
|---|---|---|
| Polite | 학생**이에요** | 의사**예요** |
| Formal | 학생**입니다** | 의사**입니다** |
| Casual | 학생**이야** | 의사**야** |

- [ ] `이에요` after a consonant, `예요` after a vowel. This is the most common beginner error in the language.
- [ ] Negative: `아니에요` — *it is not*. Also `-이/가 아니에요`.
- [ ] There is no separate adjective "to be" — Korean uses 이다 for identity and 있다/없다 for existence.

### Module 1.2.2 — 있다 / 없다

- [ ] Korean has no verb "to have". You say *"time exists"*: `시간이 있어요`.
- [ ] `있어요` = there is / I have. `없어요` = there isn't / I don't have.
- [ ] This structure explains the entire 있다/없다 word family: 맛있다/맛없다, 재미있다/재미없다, 의미있다/의미없다.

> **Module completion gate (1.2).** You produce 이에요/예요 correctly in 20 out of 20 cases, and you can say five things you have and five you don't without using a word for "have".

## 1.3 — Greetings, address, and the first thirty chunks

**Objective.** The social layer. Korean is a language where getting the greeting wrong is a bigger error than getting the grammar wrong.

### Module 1.3.1 — The greeting system

| Korean | Use |
|---|---|
| 안녕하세요 | any time, any register, the universal greeting |
| 안녕히 계세요 | goodbye — *you* are leaving, they stay |
| 안녕히 가세요 | goodbye — *they* are leaving, you stay |
| 만나서 반갑습니다 | nice to meet you |
| 잘 부탁합니다 | please look after me — first meetings, new jobs |
| 수고하셨습니다 | thank you for your work — end of a day |

- [ ] The 계세요/가세요 distinction is a small test of whether you actually know Korean. Get it right.

### Module 1.3.2 — Address terms and why they matter

| Term | Use |
|---|---|
| 씨 | after a full name, same age or younger — polite but not deferential |
| 님 | after a title or role — 선생님, 고객님 |
| 선배 / 후배 | senior / junior in school or work |
| 형 / 오빠 | older brother — male / female speaker |
| 누나 / 언니 | older sister — male / female speaker |
| 동생 | younger sibling |

- [ ] You cannot call someone by their bare name unless you are close and the same age. `민수 씨` is fine; `민수` alone is intimate or rude.
- [ ] Age determines the register. Koreans ask it early: `나이가 어떻게 되세요?` (polite) or `몇 살이에요?` (same age or younger).

### Module 1.3.3 — The thirty chunks

- [ ] 안녕하세요 · 감사합니다 · 고마워요 · 죄송합니다 · 미안해요 · 네 · 아니요 · 괜찮아요 · 잠시만요 · 여기요 · 저기요 · 실례합니다 · 잘 모르겠어요 · 다시 말해 주세요 · 천천히 말해 주세요 · 한국어로 말해 주세요 · 영어 할 수 있어요? · 얼마예요? · 이거 주세요 · 계산해 주세요 · 화장실이 어디예요? · 여기 앉아도 돼요? · 도와주세요 · 길을 잃었어요 · 괜찮습니다 · 맛있어요 · 너무 비싸요 · 카드 돼요? · 포장해 주세요 · 다음에 또 만나요

> **Module completion gate (1.3).** All thirty chunks produced from English prompts in under four minutes, with correct politeness, and 안녕히 계세요 vs 안녕히 가세요 never confused.

## 1.4 — Numbers: the two systems

**Objective.** Own the split. Mixing Sino and native numbers is the most recognisable beginner error.

### Module 1.4.1 — The two series

| # | Sino | Native | # | Sino | Native |
|---|---|---|---|---|---|
| 1 | 일 | 하나 | 6 | 육 | 여섯 |
| 2 | 이 | 둘 | 7 | 칠 | 일곱 |
| 3 | 삼 | 셋 | 8 | 팔 | 여덟 |
| 4 | 사 | 넷 | 9 | 구 | 아홉 |
| 5 | 오 | 다섯 | 10 | 십 | 열 |

- [ ] Sino: 100 백, 1,000 천, 10,000 **만**. Korean groups by ten-thousands, not thousands. 100,000 = 십만; 1,000,000 = 백만.
- [ ] Native: 20 스물, 30 서른, 40 마흔, 50 쉰, and then the system effectively stops at 99.

### Module 1.4.2 — Which where

| Use | System |
|---|---|
| money, phone numbers, dates, minutes, floors | Sino |
| **hours, age, counting things** | **Native** |

> **The sentence that proves you learned it:** `세 시 삼십 분` — 3:30. Native for the hour, Sino for the minute.

### Module 1.4.3 — Counters

| Counter | For | Example |
|---|---|---|
| 개 | things | 사과 두 개 |
| 명 | people | 학생 세 명 |
| 분 | people (honorific) | 선생님 한 분 |
| 마리 | animals | 고양이 두 마리 |
| 권 | books | 책 세 권 |
| 잔 | cups | 커피 한 잔 |
| 병 | bottles | 맥주 두 병 |
| 번 | times | 세 번 |
| 살 | age | 스물 살 |
| 층 | floors | 오 층 |
| 장 | flat things | 표 두 장 |

- [ ] Before a counter, native numbers shorten: 하나→한, 둘→두, 셋→세, 넷→네, 스물→스무.

> **Module completion gate (1.4).** Any price to 1,000,000 won, any time, any date, and your own age — spoken without pausing, and never the wrong system.

## 1.6 — Politeness in practice

**Objective.** Avoid the two errors that make foreigners sound rude rather than foreign.

### Module 1.6.1 — The register ladder

| Register | Ending | Use |
|---|---|---|
| 합니다체 | -ㅂ니다/습니다 | formal: news, presentations, first meetings |
| 해요체 | -아/어요 | polite: the default with strangers and acquaintances |
| 해체 / 반말 | -아/어 | intimate: close friends, children, family |

- [ ] Do not use 반말 until someone explicitly invites it (`말 놓으세요`) or you are clearly close. Using it early reads as arrogance, not friendliness.
- [ ] When in doubt, 해요체. It is never wrong with a stranger.

### Module 1.6.2 — Softening

| Blunt | Softened | Effect |
|---|---|---|
| 이거 주세요 | 이거 주실 수 있어요? | more polite |
| 안 돼요 | 어려울 것 같아요 | *it seems difficult* — a soft no |
| 다시 말해 | 다시 한 번 말씀해 주시겠어요? | formal request |
| 싫어요 | 괜찮아요 | *I'm fine* — a polite refusal |

> **Module completion gate (1.6).** You deliver the same request at three politeness levels, and you can refuse something without saying a bare no.

## 2.1 — The verb: dictionary form, stem, and classes

**Objective.** See the system behind conjugation.

### Module 2.1.1 — Anatomy

- [ ] Dictionary form ends in **-다**: 가다, 먹다, 하다.
- [ ] The **stem** is the dictionary form minus 다: 가, 먹, 하.
- [ ] All endings attach to the stem. The dictionary form is a citation form, never used in speech except in writing and in the plain-style declarative.

### Module 2.1.2 — Verb classes

| Class | Ending | Behaviour |
|---|---|---|
| Action verbs (동사) | 먹다, 가다 | take tenses, -고 있다, imperatives |
| Descriptive verbs (형용사) | 좋다, 크다, 예쁘다 | conjugate like verbs but do not take imperatives or progressives |
| 이다 | copula | irregular in form, not in meaning |
| 있다/없다 | existence | behave like verbs, but 있다 as "have" takes 이/가 |

> **The trap:** Korean adjectives are verbs. `예뻐요` is a complete sentence — *she is pretty*. There is no "to be" inserted. English speakers add one for months.

> **Module completion gate (2.1).** You classify 30 given verbs into action/descriptive, and write the stem of each.

## 2.2 — The present tense

**Objective.** Conjugate any regular verb, correctly, in under two seconds.

### Module 2.2.1 — The rule

| Stem's last vowel | Ending | Example |
|---|---|---|
| ㅏ or ㅗ | **-아요** | 가다 → 가요 |
| anything else | **-어요** | 먹다 → 먹어요 |
| 하다 verbs | **-해요** | 공부하다 → 공부해요 |

### Module 2.2.2 — Contractions

| Dictionary | Path | Result |
|---|---|---|
| 오다 | 오 + 아요 | 와요 |
| 보다 | 보 + 아요 | 봐요 |
| 마시다 | 마시 + 어요 | 마셔요 |
| 기다리다 | 기다리 + 어요 | 기다려요 |
| 하다 | 하 + 여요 | 해요 |
| 좋아하다 | — | 좋아해요 |

### Module 2.2.3 — The ㅡ and ㄷ families (handled fully in 2.8)

- [ ] 쓰다 → 써요, 크다 → 커요, 바쁘다 → 바빠요.
- [ ] 듣다 → 들어요, 걷다 → 걸어요.

> **Module completion gate (2.2).** Twenty-five verbs conjugated to the polite present in under three minutes, out loud, with 90% accuracy.

## 2.3 — The past tense

**Objective.** One rule, applied to everything.

### Module 2.3.1 — The rule

`stem + 았/었 + 어요`, with the same vowel test as the present.

| Present | Past | Meaning |
|---|---|---|
| 가요 | 갔어요 | went |
| 와요 | 왔어요 | came |
| 먹어요 | 먹었어요 | ate |
| 마셔요 | 마셨어요 | drank |
| 해요 | 했어요 | did |
| 공부해요 | 공부했어요 | studied |

### Module 2.3.2 — Past of descriptive verbs

- [ ] `추워요` (it is cold) → `추웠어요` (it was cold).
- [ ] `맛있어요` → `맛있었어요`.
- [ ] Past adjectives are how you describe a completed experience: `정말 재미있었어요` — *it was really fun*.

> **Module completion gate (2.3).** Narrate yesterday in ten connected past-tense sentences, spoken, with no more than two errors.

## 2.4 — Future and intention

**Objective.** Distinguish three futures that English collapses into "will".

### Module 2.4.1 — -(으)ㄹ 거예요 (plan)

- [ ] Consonant stem → -을 거예요; vowel stem → -ㄹ 거예요.
- [ ] 먹다 → 먹을 거예요 · 가다 → 갈 거예요 · 하다 → 할 거예요.
- [ ] Past form: -ㄹ 거였어요 = *was going to*.

### Module 2.4.2 — -겠- (intention, presumption, politeness)

| Use | Example | Meaning |
|---|---|---|
| Determination | 제가 하겠습니다 | I will do it |
| Polite offer | 도와드리겠습니다 | let me help |
| Presumption | 비가 오겠어요 | it looks like rain |
| Set phrases | 잘 먹겠습니다 / 잘 먹었습니다 | before / after a meal |

### Module 2.4.3 — -(으)ㄹ게요 (promise to the listener)

- [ ] `제가 할게요` — *I'll do it* (because you asked, or as a promise).
- [ ] It only appears in the first person, and it is about the listener's expectation.

> **The distinction in one line:** `할 거예요` = my plan; `하겠습니다` = my determination, formally; `할게요` = my promise to you.

> **Module completion gate (2.4).** Describe next weekend in eight sentences, using all three futures at least once each, without slipping into the present.

## 2.5 — Negation, four ways

**Objective.** Say no precisely, and distinguish choosing not to from being unable to.

### Module 2.5.1 — The four forms

| Form | Meaning | Example |
|---|---|---|
| 안 + verb | don't (short) | 안 가요 |
| -지 않다 | don't (long) | 가지 않아요 |
| 못 + verb | can't (short) | 못 가요 |
| -지 못하다 | can't (long) | 가지 못해요 |

### Module 2.5.2 — 안 vs 못

| Korean | Meaning |
|---|---|
| 안 먹어요 | I'm not eating (by choice) |
| 못 먹어요 | I can't eat (allergy, no time, unavailable) |

- [ ] This distinction is not optional. Using 안 when you mean 못 sounds like stubbornness.

### Module 2.5.3 — Placement rules

- [ ] 안 and 못 go immediately before the verb, never before the object: `밥을 안 먹어요` ✓, `안 밥을 먹어요` ✗.
- [ ] With 하다 verbs, the 안 goes before 하다: `공부 안 해요`.
- [ ] Past negation is formed on the tense: 안 갔어요, 못 갔어요, 가지 않았어요, 가지 못했어요.

> **Module completion gate (2.5).** Twenty sentences negated both ways, with 안/못 chosen correctly and the placement never wrong.

## 2.6 — Particles I: the core three

**Objective.** 은/는, 이/가, 을/를 — the trio that carries most of the grammar and most of the confusion.

### Module 2.6.1 — 을/를 (object)

- [ ] After a consonant 을, after a vowel 를.
- [ ] Only transitive verbs take it.
- [ ] Memorise verbs with their frame: `밥을 먹다`, not `먹다`.

### Module 2.6.2 — 은/는 (topic)

- [ ] Marks what the sentence is *about*, and often contrasts.
- [ ] `저는 학생이에요` — *as for me, I'm a student*.
- [ ] It can replace 이/가 or 을/를 in the same slot: `밥은 먹어요` — *as for rice, I do eat it*.

### Module 2.6.3 — 이/가 (subject, new information)

- [ ] Marks the doer or the bearer of a state, and signals *this is the answer to the question*.
- [ ] `누가 왔어요?` → `민수 씨가 왔어요.` (not 는)
- [ ] `비가 와요` — new information, no contrast.

### Module 2.6.4 — The honest simplification

| Situation | Use |
|---|---|
| introducing a new topic | 은/는 |
| answering "who/what did X?" | 이/가 |
| contrast or comparison | 은/는 |
| neutral description with no contrast | 이/가 |
| after 있어요/없어요 | 이/가 |

> **Do not try to master this at L2.** Learn the five situations above, and let the rest come from exposure between L2 and L7. Fluency in 은/는 vs 이/가 is a late-stage skill, and no amount of rule-reading replaces hearing 1,000 examples.

> **Module completion gate (2.6).** You choose the correct particle in 20 out of 25 given sentences and can explain the choice in the five-situation table.

## 2.7 — Particles II: place, direction, person

**Objective.** The particles that answer *where*, *to whom*, and *by what means*.

### Module 2.7.1 — The table

| Particle | Function | Example |
|---|---|---|
| 에 | time, destination, existence | 세 시에 · 학교에 가요 · 집에 있어요 |
| 에서 | location of an action, source | 학교에서 공부해요 · 인도에서 왔어요 |
| 에게 / 한테 | to a person | 친구에게 말했어요 |
| 에게서 / 한테서 | from a person | 친구에게서 받았어요 |
| 께 | to/from a person (honorific) | 선생님께 드렸어요 |
| (으)로 | direction, means | 집으로 가요 · 버스로 가요 |
| 와/과, 하고, (이)랑 | and, with | 친구와 같이 · 친구하고 |
| 도 | also | 저도 가요 |
| 만 | only | 물만 마셔요 |
| 밖에 + negative | only | 물밖에 없어요 |
| 부터 / 까지 | from / until | 아침부터 밤까지 |
| 마다 | every | 주말마다 |
| 보다 | than | 나보다 커요 |
| 처럼 | like | 친구처럼 |

### Module 2.7.2 — The three that get confused

- [ ] **에 vs 에서.** Movement toward or existence at a place → 에. An action performed there → 에서.
- [ ] **만 vs 밖에.** Both mean "only", but 밖에 always requires a negative verb: `물밖에 없어요`.
- [ ] **하고 vs 와/과.** Same meaning; 하고 is spoken and can be used with any noun, 와/과 is written and more formal.

> **Module completion gate (2.7).** 25 sentences with particles blanked out, 22+ correct, with the reason stated for each.

## 3.1 — Clause linking I: and, but, so

**Objective.** Stop producing sentences one at a time.

### Module 3.1.1 — -고 (and, and then)

- [ ] Attaches to the stem with no tense: 먹**고**, 가**고**, 하**고**.
- [ ] Tense appears only on the final verb: `밥을 먹고 학교에 갔어요`.
- [ ] It sequences, it does not cause. `비가 오고 추워요` — it rains and (also) it's cold.

### Module 3.1.2 — -지만 (but)

- [ ] `비싸지만 좋아요` — it's expensive but I like it.
- [ ] Can attach to past stems: `갔지만`.

### Module 3.1.3 — -는데 (background, contrast, softening)

- [ ] The most versatile connector in the language, and the last one learners acquire.
- [ ] Background: `지금 바쁜데요…` — *I'm busy right now (so…)*
- [ ] Contrast: `한국어는 어려운데 재미있어요`.
- [ ] Softening a request: `죄송한데요, 다시 말씀해 주시겠어요?`
- [ ] Conjugation: verb stem + 는데; descriptive stem + -(으)ㄴ데; past + -았/었는데.

> **Module completion gate (3.1).** Twenty linked sentences using -고, -지만, -는데 correctly, with the tense only on the final verb.

## 3.2 — Reason and cause: the three-way distinction

**Objective.** The distinction that separates intermediate speakers from phrasebook speakers.

### Module 3.2.1 — The comparison

| Pattern | Nuance | Restriction |
|---|---|---|
| -아/어서 | neutral reason, sequential cause | **cannot** be followed by an imperative or a proposal |
| -(으)니까 | reason the listener should accept; discovery | can be followed by imperatives and suggestions |
| -기 때문에 | formal, emphatic reason | any ending, but stiff |

### Module 3.2.2 — The rule people get wrong

- [ ] `비가 와서 못 갔어요` ✓ (statement)
- [ ] `비가 오니까 우산을 가져가세요` ✓ (imperative — only 니까 works)
- [ ] `비가 와서 우산을 가져가세요` ✗ (grammatically wrong)

- [ ] Second use of -니까: discovery. `가 보니까 사람이 없었어요` — *I went and found nobody there.*

> **Module completion gate (3.2).** You choose correctly between 서 and 니까 in 15 sentences, and you can state the imperative restriction without notes.

## 3.3 — Purpose, intention, and attempt

**Objective.** Say why you went somewhere and what you intend to do.

### Module 3.3.1 — The purpose patterns

| Pattern | Meaning | Example |
|---|---|---|
| -(으)러 가다/오다 | go/come in order to | 밥을 먹으러 가요 |
| -(으)려고 하다 | intend to | 내일 가려고 해요 |
| -(으)려고요 | casual intention | 지금 가려고요 |
| -기 위해(서) | in order to (formal, written) | 성공하기 위해서 노력해요 |

### Module 3.3.2 — Attempt and completion

- [ ] -아/어 보다 — try: 먹어 봤어요 (I've tried it).
- [ ] -고 싶다 — want: 가고 싶어요.
- [ ] -고 싶어하다 — third person: 그 사람은 가고 싶어해요. You cannot use 싶다 about someone else's inner state.

> **Module completion gate (3.3).** Ten purpose sentences, ten intention sentences, and the third-person rule produced correctly.

## 3.4 — Time and condition

**Objective.** Build the time clauses that make a narrative possible.

### Module 3.4.1 — The table

| Pattern | Meaning | Example |
|---|---|---|
| -(으)면 | if, when (conditional) | 비가 오면 안 가요 |
| -(으)ㄹ 때 | when (at the time of) | 어릴 때 |
| -았/었을 때 | when (past) | 학생이었을 때 |
| -자마자 | as soon as | 도착하자마자 전화했어요 |
| -는 동안 | while, during | 공부하는 동안 |
| -기 전에 | before | 가기 전에 |
| -(으)ㄴ 후에 | after | 먹은 후에 |
| -(으)ㄹ 때까지 | until | 끝날 때까지 |

### Module 3.4.2 — The tense trap

- [ ] Time clauses take tense only where the time reference differs from the main clause: `비가 왔을 때 집에 있었어요` (it rained, I was home — both past).
- [ ] `-면` takes no tense at all: 비가 오면, never 비가 왔으면 (that would be counterfactual, a different pattern at L10).

> **Module completion gate (3.4).** A six-sentence narrative using at least five different time patterns, with no tense error in the subordinate clause.

## 3.5 — Nominalisation

**Objective.** Turn verbs into nouns so they can be subjects, objects, and topics. This unlocks a large fraction of intermediate grammar.

### Module 3.5.1 — The three forms

| Form | Use | Example |
|---|---|---|
| -는 것 | the general, spoken form | 공부하는 것이 재미있어요 |
| -기 | often with certain verbs (시작하다, 좋아하다, 어렵다) | 공부하기 어려워요 |
| -(으)ㅁ | formal, written, and in some fixed patterns | 사실임을 알았어요 |

### Module 3.5.2 — The fixed patterns this unlocks

- [ ] -는 것이 좋겠어요 — you'd better
- [ ] -기로 하다 — decide to
- [ ] -기 시작하다 — begin to
- [ ] -기 때문에 — because (formal)
- [ ] -(으)ㅁ에도 불구하고 — despite

> **Module completion gate (3.5).** You convert ten sentences into nominalised forms and use three fixed patterns correctly.

## 3.6 — Noun modifiers: the adjectival engine

**Objective.** Put a whole clause in front of a noun. This is where Korean becomes compact and where English speakers slow down.

### Module 3.6.1 — The four modifiers

| Tense | Ending | Example |
|---|---|---|
| Present (verb) | -는 | 먹는 사람 |
| Present (adjective) | -(으)ㄴ | 예쁜 사람 |
| Past | -(으)ㄴ | 먹은 사람 |
| Future / supposition | -(으)ㄹ | 먹을 사람 |

- [ ] Note the collision: `-(으)ㄴ` is past for verbs and present for adjectives.
- [ ] `-던` = used to, or was in the middle of: `내가 살던 집` — the house I used to live in.

### Module 3.6.2 — The long modifier

- [ ] `어제 만난 사람이 선생님이에요` — the person I met yesterday is a teacher.
- [ ] Korean puts the whole relative clause before the noun, with no "who/which". Long modifiers are the main reason reading comprehension slows at intermediate level.

> **Module completion gate (3.6).** Fifteen noun phrases built from clauses, then used in full sentences.

## 3.7 — Honorifics in full

**Objective.** Operate the whole system, not just the -시- suffix.

### Module 3.7.1 — The three axes

| Axis | Mechanism | Example |
|---|---|---|
| Subject honour | -시-, 께서, honorific vocabulary | 선생님께서 드세요 |
| Object honour | special verbs (드리다, 뵙다, 여쭙다) | 선생님께 여쭀어요 |
| Hearer honour | the register (합니다 / 해요 / 해) | — |

- [ ] All three operate at once. A sentence can be simultaneously subject-honorific, object-honorific, and hearer-polite.
- [ ] The classic error: over-honorifying yourself. `저께서` is wrong — you never honour your own actions with 께서 in the same way.

### Module 3.7.2 — The humble verbs

| Plain | Humble | Meaning |
|---|---|---|
| 주다 | 드리다 | give |
| 보다 | 뵙다 | meet |
| 묻다 | 여쭙다 | ask |
| 말하다 | 말씀드리다 | say (to a superior) |
| 데려가다 | 모시고 가다 | take someone along |

> **Module completion gate (3.7).** Ten sentences converted into full honorific form, using all three axes, with no over-honorification of the self.

## 3.8 — Comparison

**Objective.** Express degree, preference, and similarity.

### Module 3.8.1 — The comparison set

| Pattern | Meaning | Example |
|---|---|---|
| A가 B보다 | A is more than B | 한국어가 영어보다 어려워요 |
| 더 / 덜 | more / less | 더 커요 |
| 가장 / 제일 | most | 제일 좋아요 |
| 만큼 | as much as | 생각만큼 어렵지 않아요 |
| 처럼 / 같이 | like | 친구처럼 |
| -보다 나은 | better than | — |
| 별로 | not particularly | 별로 안 좋아요 |

> **Module completion gate (3.8).** Ten comparisons using five different patterns, spoken, with no English word order bleeding in.

## 3.9 — Discourse: making it hold together

**Objective.** The difference between correct sentences and a coherent answer.

### Module 3.9.1 — The connectors of speech

| Marker | Function |
|---|---|
| 근데 / 그런데 | but, by the way — the most common turn in speech |
| 그래서 | so |
| 그러니까 | so, I mean |
| 그리고 | and |
| 근데요 | softening opener |
| 사실은 | actually |
| 어쨌든 | anyway |
| 아무튼 | in any case |
| 즉 | that is |
| 예를 들어 | for example |

### Module 3.9.2 — Fillers that buy time

- [ ] 저기… · 음… · 뭐라고 할까… · 그러니까… · 약간…
- [ ] Using fillers deliberately is a fluency marker, not a weakness. Silent pauses read as failure; filled pauses read as thinking.

> **Module completion gate (3.9).** A 90-second monologue using at least six discourse markers naturally, with no dead air longer than 2 seconds.

## 3.10 — Level 3 Capstone: `story-engine`

**Objective.** A three-minute spoken narrative that a native speaker would call fluent.

### A. Functional requirements

1. **The story.** A true story from your life, 3 minutes, told without notes, recorded on video.
2. **The transcript.** Written out in Hangeul, with a gloss and a grammar annotation for every clause connector.
3. **The structure.** A clear beginning, three developments, and an ending — marked explicitly in the transcript.
4. **The connector inventory.** Every linking pattern used, with a count, targeting at least ten distinct patterns.
5. **The tense audit.** All three tenses used correctly; the narrative must have a past main line and a present reflection.
6. **The revision log.** Three recorded takes with the improvements listed between them.
7. **The comprehension check.** A native speaker or advanced learner listens once and retells the story — the retelling must be accurate.

### B. Suggested architecture

```
story-engine/
├── story/
│   ├── transcript.md        ← Hangeul | gloss | connector annotation
│   ├── structure.md         ← opening / development 1-3 / ending
│   └── take_1.mp4  take_2.mp4  take_final.mp4
├── connectors/
│   └── inventory.md         ← pattern | count | example from the story
├── tense_audit.md
├── revision_log.md          ← take N | what changed | why
└── comprehension/
    └── listener_retelling.md
```

### C. Acceptance targets

| Dimension | Target |
|---|---|
| Length | 2:30–3:30 |
| Connectors | ≥ 10 distinct patterns, used correctly |
| Tense accuracy | ≥ 95% |
| Honorific accuracy | no errors in the framed opening and closing |
| Fluency | ≤ 5 hesitations over 1 second; no dead air over 2 seconds |
| Comprehension | listener retells the story accurately |
| Structure | beginning, development, end all clearly marked |

### D. Stretch goals

- Tell the same story to two different listeners and adapt the register for each.
- Add reported speech (a preview of L8): *"she said that…"*
- Tell a story in the future tense — describing what will happen.

### E. Acceptance criteria table

| Row | Criterion | Weight | Evidence |

# PHASE 1 CAPSTONE — THE FIRST HOUR

> **The brief.** Spend sixty minutes entirely in Korean. No English, no dictionary app, no switching. One conversation, one topic, one hour.

## A. Functional requirements

1. **Duration.** 55–65 minutes, continuous, with a tutor, an exchange partner, or a native speaker.
2. **No English.** Zero English words, zero code-switching. If you cannot say something, you must circumlocute — describe it another way.
3. **Topic coverage.** At least four of: your work or study, your family, your city, a trip you took, a film or book you liked, a plan for next year.
4. **Grammar coverage.** At least one instance each of: past, present, future, negation (both 안 and 못), a connector, a noun modifier, an honorific sentence.
5. **Repair.** At least three instances of asking for clarification *in Korean*, and at least one of correcting yourself mid-sentence.
6. **The recording and the transcript.** Full audio, plus a 15-line transcript of the most and least successful exchanges.
7. **The retrospective.** Written, in Korean if possible, answering: what did I avoid saying, and what structure would have let me say it?

## B. Suggested architecture

```
first-hour/
├── recording.mp3
├── topic_map.md            ← the four topics, in order, with what you wanted to say vs said
├── grammar_checklist.md    ← each required pattern, with the timestamp where you used it
├── repair_log.md           ← three clarifications + one self-correction
├── transcript.md           ← 15 lines: best and worst exchanges
└── retrospective.md        ← what I avoided, and the structure I needed
```

## C. Acceptance targets

| Dimension | Target |
|---|---|
| Duration | 55+ minutes continuous |
| English used | zero |
| Topics | 4+ distinct |
| Grammar coverage | all seven required patterns evidenced |
| Comprehension | you understood ≥ 85% of what the partner said |
| Repair | 3+ clarifications, 1+ self-correction |
| Avoidance | ≤ 3 topics abandoned for lack of vocabulary |

## D. Stretch goals

# APPENDIX

## A. Sound-change quick reference

| Rule | Trigger | Result | Example |
|---|---|---|---|
| Liaison | batchim + ㅇ onset | final moves forward | 한국어 → [한구거] |
| Aspiration | ㄱ/ㄷ/ㅂ/ㅈ + ㅎ | ㅋ/ㅌ/ㅍ/ㅊ | 좋다 → [조타] |
| Tensification | stop batchim + ㄱ/ㄷ/ㅂ/ㅅ/ㅈ | doubled | 학교 → [학꾜] |
| Nasalisation | stop batchim + ㄴ/ㅁ | ㅇ/ㄴ/ㅁ | 국물 → [궁물] |
| Liquidisation | ㄴ + ㄹ, ㄹ + ㄴ | ㄹㄹ | 신라 → [실라] |
| Palatalisation | ㄷ/ㅌ + 이 | 지/치 | 같이 → [가치] |
| ㅎ deletion | ㅎ + vowel, ㅎ + ㄴ/ㅁ | ㅎ drops | 괜찮아요 → [괜차나요] |

## B. Conjugation quick reference

| Tense / form | Rule | 먹다 | 가다 | 하다 |
|---|---|---|---|---|
| Present polite | -아/어요 | 먹어요 | 가요 | 해요 |
| Past polite | -았/었어요 | 먹었어요 | 갔어요 | 했어요 |
| Future | -(으)ㄹ 거예요 | 먹을 거예요 | 갈 거예요 | 할 거예요 |
| Formal present | -ㅂ니다 | 먹습니다 | 갑니다 | 합니다 |
| Formal past | -았/었습니다 | 먹었습니다 | 갔습니다 | 했습니다 |
| Negation (short) | 안 + V | 안 먹어요 | 안 가요 | 안 해요 |
| Negation (long) | -지 않다 | 먹지 않아요 | 가지 않아요 | 하지 않아요 |
| Cannot | 못 + V | 못 먹어요 | 못 가요 | 못 해요 |
| Ability | -(으)ㄹ 수 있다 | 먹을 수 있어요 | 갈 수 있어요 | 할 수 있어요 |
| Must | -아/어야 하다 | 먹어야 해요 | 가야 해요 | 해야 해요 |
| May | -아/어도 되다 | 먹어도 돼요 | 가도 돼요 | 해도 돼요 |
| Progressive | -고 있다 | 먹고 있어요 | 가고 있어요 | 하고 있어요 |
| Honorific | -(으)시- | 드세요 | 가세요 | 하세요 |
