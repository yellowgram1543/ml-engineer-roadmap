# PHASE 3 — INTERMEDIATE RANGE

**Korean Roadmap · Levels 7–9 of 18**

> **Phase goal.** Move from *can handle situations* to *can think in the language*. By the end of this phase you argue a position for five minutes with structure and concession, quote other people accurately with the right hearsay marker, describe events in the passive and the causative, and move between four registers without slipping.
>
> **The shift.** Phases 1 and 2 taught you to survive situations. Phase 3 teaches you to hold a *position* — and the grammar for that is a different order of difficulty. A request is one clause. An argument is a structure: claim, reason, example, concession, conclusion — each with its own ending, and each with a politeness level that has to stay consistent across all five.

# LEVEL 7 — DISCOURSE AND CONNECTORS

> **Goal.** Hold the floor. Say something for five minutes that has a beginning, three reasons, a concession, and an end — in the right register, without the listener having to work to follow you.

## 7.1 — The architecture of a Korean answer

**Objective.** Understand the shape a Korean listener expects before you have any new grammar.

### Module 7.1.1 — The five-part answer

| Part | Korean | Function |
|---|---|---|
| **1 · Framing** | 제 생각에는… / 이 질문에 대해… | signals that a long answer is coming, buys time |
| **2 · Position** | 저는 ___라고 생각합니다. | the claim, stated early — not at the end |
| **3 · Reasons** | 첫째, … 둘째, … | two or three, each with a marker |
| **4 · Concession** | 물론 ___지만… | shows you have considered the other side |
| **5 · Close** | 그래서 ___라고 생각합니다. | restates the claim, slightly differently |

- [ ] Unlike English academic style, the position comes **early**. A Korean listener who waits 90 seconds for the thesis assumes you do not have one.
- [ ] The concession is not optional. An answer with no concession reads as naive.
- [ ] The close restates, it does not add a new point.

### Module 7.1.2 — Why this is hard

- [ ] Every part has its own ending, and the register has to stay consistent across all five.
- [ ] The connectives carry much of the meaning, so a wrong one changes the argument, not just the grammar.
- [ ] Korean discourse is more **listener-oriented**: you signal your direction constantly (`크게 두 가지가 있는데요…`) rather than surprising the listener.

> **Module completion gate (7.1).** You deliver a 90-second answer using all five parts, labelled out loud ("여기서부터 이유입니다"), and a listener can name your position after hearing it once.

## 7.2 — Cause and reason: the refined set

**Objective.** L3 gave you 서 and 니까. These are the six that carry nuance.

### Module 7.2.1 — The reason table

| Pattern | Nuance | Restriction | Example |
|---|---|---|---|
| **-아/어서** | neutral cause | no imperative, no suggestion | 비가 와서 못 갔어요 |
| **-(으)니까** | reason the listener should accept; discovery | can take imperatives | 비가 오니까 우산 챙기세요 |
| **-기 때문에** | formal, emphatic, written | any ending, but stiff | 시간이 없기 때문에 못 갔습니다 |
| **-느라고** | a reason that *occupied* you, usually with a negative result | subject must be the same, present/past only | 공부하느라고 잠을 못 잤어요 |
| **-는 바람에** | an unwelcome cause with a bad outcome | past result, negative | 버스가 늦는 바람에 지각했어요 |
| **-는 통에** | a noisy/chaotic cause | negative, colloquial | 옆집이 시끄러운 통에 못 잤어요 |
| **-길래** | because I saw/heard that, so I acted | first person action in the result | 비가 오길래 우산을 챙겼어요 |

### Module 7.2.2 — The three you will actually use

- [ ] **-느라고** takes the blame: `전화 받느라고 못 봤어요` — I didn't see it because I was on the phone.
- [ ] **-는 바람에** assigns an external cause to a bad result: `지하철이 멈추는 바람에 늦었어요`.
- [ ] **-길래** reports a perceived cause: `맛있어 보이길래 샀어요` — it looked good so I bought it.

> **The constraint that matters:** -느라고 and -는 바람에 cannot be followed by a request or a command. If you add `-세요`, the sentence collapses. Same restriction as -아/어서, and the same reason: the speaker is reporting, not directing.

> **Module completion gate (7.2).** Fifteen cause sentences, each using a *different* pattern, with the nuance explained in one clause.

## 7.3 — Contrast and concession

**Objective.** Disagree without rupturing the conversation. This is a social skill expressed as grammar.

### Module 7.3.1 — The contrast ladder

| Pattern | Strength | Example |
|---|---|---|
| **-지만** | neutral contrast | 비싸지만 좋아요 |
| **-는데** | background, softening, mild contrast | 비싼데 좀 별로예요 |
| **-기는 하지만** | concede then contradict | 맛있기는 하지만 비싸요 |
| **-(으)ㄴ/는데도** | despite | 노력했는데도 안 됐어요 |
| **-더라도** | even if (hypothetical, strong) | 힘들더라도 해야 해요 |
| **-아/어도** | even if, even though | 가도 괜찮아요 |
| **-ㄴ다 해도** | even granting that | 네 말이 맞다 해도 문제는 남아요 |
| **-반면에** | on the other hand (written, balanced) | 도시는 편리한 반면에 비싸요 |
| **-에 비해** | compared to | 작년에 비해 나아졌어요 |

### Module 7.3.2 — The concession move

- [ ] `물론 ___지만, 그래도 ___` — of course X, but even so Y. This is the single most useful argumentative structure in Korean.
- [ ] `-기는 하지만` is the softened version and is what makes you sound reasonable rather than combative.
- [ ] `-는데도` is *despite*, and it carries frustration. Do not use it about a person in a formal setting.

> **Module completion gate (7.3).** Ten concessions, each conceding a real point and then contradicting it, delivered to a tutor who argues back.

## 7.4 — Sequence, condition, and discovery

**Objective.** The connectors that carry a narrative and an argument forward.

### Module 7.4.1 — The table

| Pattern | Meaning | Example |
|---|---|---|
| **-고 나서** | after finishing | 밥을 먹고 나서 갔어요 |
| **-자마자** | as soon as | 도착하자마자 전화했어요 |
| **-는 대로** | as soon as, or as-is | 도착하는 대로 연락할게요 |
| **-다가** | while doing, then switched | 걷다가 넘어졌어요 |
| **-았/었더니** | I did X and discovered | 가 봤더니 문이 닫혀 있었어요 |
| **-(으)면** | if, when | 비가 오면 안 가요 |
| **-거든** | if indeed (speaker's premise) | 돈이 있거든 좀 빌려줘 |
| **-지 않으면 / 아니면** | unless, otherwise | 지금 안 가면 늦어요 |
| **-(으)ㄹ수록** | the more… the more | 배울수록 재미있어요 |
| **-도록** | so that, to the extent | 늦지 않도록 서두르세요 |

### Module 7.4.2 — The two that carry the most meaning

- [ ] **-았/었더니** combines a past action with a discovery, and the second clause must be a *result you observed*: `전화했더니 안 받더라고요`.
- [ ] **-(으)ㄹ수록** is a rhetorical favourite: `생각할수록 화가 나요` — the more I think, the angrier I get.

> **Module completion gate (7.4).** A six-sentence narrative using five different sequence connectors, with no tense error in the subordinate clauses.

## 7.5 — Hedging, softening, and stance

**Objective.** Say what you think without claiming to be certain. Korean argument is built out of hedges.

### Module 7.5.1 — The hedge ladder

| Certainty | Form | Example |
|---|---|---|
| I'm sure | -다고 확신해요 | 맞다고 확신해요 |
| I think | -다고 생각해요 | 맞다고 생각해요 |
| It seems | -(으)ㄴ/는 것 같아요 | 맞는 것 같아요 |
| It looks like (from evidence) | -나 봐요 | 비가 오나 봐요 |
| It must be | -(으)ㄴ가 봐요 | 피곤한가 봐요 |
| Apparently | -대요 | 비가 온대요 |
| I might be wrong but | 제가 틀릴 수도 있는데 | |
| It wouldn't be a bad idea | -는 것도 괜찮을 것 같아요 | |

### Module 7.5.2 — Softening a claim

| Too strong | Softened |
|---|---|
| 이건 틀렸어요 | 이건 좀 다른 것 같아요 |
| 그건 아니에요 | 그렇게 보기는 어려울 것 같아요 |
| 반대해요 | 저는 조금 다르게 생각해요 |
| 안 됩니다 | 어려울 것 같습니다 |

- [ ] In Korean professional speech, the stronger the disagreement, the softer the wording. Bluntness is not honesty — it is a register error.
- [ ] `-것 같아요` is not weakness. It is the default stance of a polite adult expressing an opinion.

> **Module completion gate (7.5).** You disagree with ten statements, each at a different level of directness, and state which level suits which setting.

## 7.6 — Building an argument

**Objective.** The vocabulary and structure of reasoned speech.

### Module 7.6.1 — The markers

| Function | Korean |
|---|---|
| Framing | 제 생각에는 · 개인적으로는 · 이 문제에 대해 |
| Ordering | 첫째 · 둘째 · 셋째 · 먼저 · 다음으로 · 마지막으로 |
| Adding | 게다가 · 뿐만 아니라 · 또한 |
| Exemplifying | 예를 들어 · 실제로 · 구체적으로 말하면 |
| Contrasting | 반면에 · 이에 비해 · 한편 |
| Conceding | 물론 · 사실 · 인정하지만 |
| Emphasising | 특히 · 무엇보다 · 정말 |
| Concluding | 결론적으로 · 그래서 · 따라서 |

### Module 7.6.2 — The five-minute skeleton

| Minute | Content | Opening phrase |
|---|---|---|
| 0:00–0:30 | Frame and state the position | 이 질문에 대해 저는 ___라고 생각합니다. |
| 0:30–1:30 | Reason 1 + example | 첫째, ___ 때문입니다. 예를 들어 ___ |
| 1:30–2:30 | Reason 2 + example | 둘째, ___ |
| 2:30–3:30 | Reason 3 or a personal experience | 셋째, 제 경험으로는 ___ |
| 3:30–4:15 | Concession | 물론 ___라는 의견도 있습니다. 하지만 ___ |
| 4:15–5:00 | Close and call to action | 그래서 저는 ___라고 생각합니다. |

- [ ] Rehearse the skeleton on five different topics. The topics do not matter; the shape does.
- [ ] The concession is where most learners fall apart, because it requires switching sides for two sentences while keeping the register.

> **Module completion gate (7.6).** A five-minute argument on a prepared topic, recorded, scored against the skeleton with every part present.

## 7.7 — Counter-argument and repair

**Objective.** Handle being interrupted, contradicted, and corrected — which is what a real discussion is.

### Module 7.7.1 — The moves

| Situation | Korean |
|---|---|
| Acknowledge a point | 그 지적은 타당합니다 / 그 부분은 맞습니다 |
| Partially concede | 그런 면도 있지만 |
| Redirect | 그 얘기도 중요하지만, 제가 말씀드린 건 |
| Ask for the objection | 어떤 점이 우려되시는지 말씀해 주시겠어요? |
| Buy time | 잠시만요, 정리해서 말씀드리면 |
| Restate more clearly | 다시 말해서 ___라는 겁니다 |
| Admit you don't know | 그 부분은 제가 잘 모르겠습니다. 확인해 보겠습니다 |
| Correct yourself | 아, 죄송합니다. ___가 아니라 ___입니다 |

### Module 7.7.2 — The rule of the interruption

- [ ] Do not restart the whole argument when interrupted. Answer the specific objection, then return with `그래서 처음에 말씀드린 것처럼…`.
- [ ] `그 부분은 제가 잘 모르겠습니다` is a strong answer, not a weak one. Confident ignorance beats invented facts.

> **Module completion gate (7.7).** You argue a position while a tutor interrupts three times with objections, and you return to your thread each time without restarting.

## 7.8 — Speech markers and fillers

**Objective.** Sound like a speaker rather than a textbook.

### Module 7.8.1 — The marker set

| Marker | Function |
|---|---|
| 근데 / 그런데 | but, by the way — the commonest turn in speech |
| 그러니까 | so, I mean — rephrasing |
| 어쨌든 / 아무튼 | anyway |
| 사실은 | actually |
| 뭐랄까 | how shall I put it |
| 말하자면 | so to speak |
| 약간 | kind of, a bit — the universal softener |
| 막 | like, or something — intensifier in slang |
| 좀 | a bit — politeness softener |
| 이제 | now, then — a filler that means nothing |
| 뭔가 | something, somehow |
| 되게 / 진짜 / 완전 | really — three levels of intensity |

### Module 7.8.2 — Why fillers matter

- [ ] A silent pause reads as failure; a filled pause reads as thinking. This is the single biggest cheap improvement available at this level.
- [ ] `약간` and `좀` make almost any sentence sound more natural and less aggressive.
- [ ] `막` and `완전` belong to casual speech only — using them in a formal setting is a register error, not a vocabulary error.

> **Module completion gate (7.8).** A three-minute monologue with no dead air over two seconds, using at least eight different markers.

## 7.9 — Emphasis, rephrasing, and self-repair

**Objective.** Control the listener's attention.

### Module 7.9.1 — The emphasis devices

| Device | Korean | Effect |
|---|---|---|
| Restatement | 즉 · 다시 말해서 · 그러니까 | clarifies |
| Reformulation | 말하자면 · 쉽게 말하면 | simplifies |
| Definition | ___란 ___이다 | defines |
| Emphasis | 특히 · 무엇보다도 · 정말로 | highlights |
| Double negative | 안 ___할 수 없다 | strong affirmation |
| Rhetorical question | 그게 무슨 말이겠어요? | dismisses |

### Module 7.9.2 — Self-repair

- [ ] `아, 그게 아니라` — no, that's not it (the commonest repair)
- [ ] `다시 말하면` — let me rephrase
- [ ] `제가 말을 잘못했는데` — I said that badly
- [ ] `그게 아니라, ___` — it's not that, it's ___
- [ ] Repairing is a *fluency* behaviour. Learners who never repair sound worse than learners who repair often.

> **Module completion gate (7.9).** You deliver a two-minute answer containing at least two self-repairs, both smooth enough that the argument does not break.

## 7.10 — The extended monologue

**Objective.** Sustain five minutes without notes. This is the level's real skill.

### Module 7.10.1 — The stamina ladder

| Stage | Duration | Structure |
|---|---|---|
| 1 | 90 s | position + one reason |
| 2 | 2 min | position + two reasons |
| 3 | 3 min | position + two reasons + concession |
| 4 | 4 min | + personal experience |
| 5 | 5 min | + counter-argument you pre-empt |

### Module 7.10.2 — The ten-topic drill

- [ ] Prepare nothing. A partner names a topic; you speak for the target time.
- [ ] Topics should be ordinary: remote work, learning languages, city versus countryside, social media, university education, AI, food culture, exercise, travel, money.
- [ ] Record every attempt. The measure is *time sustained without a break longer than three seconds*.

> **Module completion gate (7.10).** Five minutes on an unprepared topic, recorded, with ≥ 4.5 minutes of speech and no break over three seconds.

## 7.11 — Level 7 Capstone: `argument-lab`

**Objective.** A recorded argument with a live Q&A, scored on structure.

### A. Functional requirements

1. **The prepared argument.** Five minutes on a topic of your choice, with the full five-part skeleton.
2. **The unprepared argument.** Five minutes on a topic given at random, forty seconds of thinking time.
3. **The concession drill.** Three recorded clips where you concede a point, then contradict it.
4. **The Q&A.** Ten minutes of questions from a tutor, including two hostile ones.
5. **The connector inventory.** Every connector used, with a count and a context.
6. **The self-review.** A transcript of the prepared argument with the skeleton annotated in the margin.
7. **The repair log.** Every self-repair, hesitation, and breakdown, with what you should have said.

- Argue the *opposite* of your position, convincingly.
- Argue with two people at once.
- Argue on a topic where you have no vocabulary, using circumlocution.

# LEVEL 8 — REPORTED SPEECH, PASSIVE, AND CAUSATIVE

> **Goal.** Move other people's words, and change the direction of a verb. By the end you report what someone said with the correct hearsay marker, describe being acted upon without sounding like a translated English sentence, and distinguish the passive from the causative where Korean uses the same suffix for both.

## Level dashboard

| Item | Details |
|---|---|
| **Level** | 8 — Reported Speech, Passive, and Causative |
| **Difficulty** | Upper-intermediate |
| **Suggested duration** | 4–5 weeks |
| **Study commitment** | 2–3 hours per day |

## 8.1 — The four quote types

**Objective.** One system, four endings, and the difference between quoting a statement, a question, a suggestion, and a command.

### Module 8.1.1 — The system

| Quote type | Ending | Example |
|---|---|---|
| Statement | **-다고** | 간다고 했어요 — he said he's going |
| Question | **-냐고** | 간냐고 물었어요 — she asked if I'm going |
| Suggestion | **-자고** | 가자고 했어요 — he suggested we go |
| Command | **-라고** | 가라고 했어요 — he told me to go |

### Module 8.1.2 — The tense inside the quote

- [ ] Korean does **not** backshift tense the way English does. `간다고 했어요` = *he said he is going / was going*. The time is carried by the outer verb and the context.
- [ ] To be explicit: past `갔다고 했어요`, future `갈 거라고 했어요`.
- [ ] The outer verb can be anything: 말하다, 하다, 생각하다, 믿다, 듣다, 물어보다, 쓰다.

### Module 8.1.3 — The copula and the irregular quotes

| Direct | Reported |
|---|---|
| 학생이에요 | 학생이라고 했어요 |
| 학생이 아니에요 | 학생이 아니라고 했어요 |
| 뭐예요? | 뭐냐고 물었어요 |
| 같이 가요 | 같이 가자고 했어요 |
| 하지 마세요 | 하지 말라고 했어요 |

> **The one everyone gets wrong:** 이다 takes **-라고**, not -다고. `학생이라고 했어요`, never `학생이다고 했어요`.

> **Module completion gate (8.1).** Twenty sentences converted from direct to reported speech, all four quote types, with the copula correct every time.

## 8.2 — Short forms and hearsay

**Objective.** The contracted quotes that make up most of what you actually hear.

### Module 8.2.1 — The contraction table

| Full | Contracted | Meaning |
|---|---|---|
| -다고 해요 | **-대요** | they say |
| -냐고 해요 | **-냬요** | they ask |
| -자고 해요 | **-재요** | they suggest |
| -라고 해요 | **-래요** | they say (copula or command) |
| -다고 했어요 | -댔어요 | they said |
| -(으)ㄴ다고요 | -(으)ㄴ다구요 | (confirming what you just heard) |

### Module 8.2.2 — What each one tells you

| Ending | Source of information | Example |
|---|---|---|
| **-대요** | second-hand, no commitment | 내일 온대요 — I hear they're coming tomorrow |
| **-더라고요** | I experienced it myself | 내일 온다더라고요 — they told me they're coming |
| **-다면서요** | I heard, and I'm checking | 내일 온다면서요? — so you're coming tomorrow? |
| **-다고요?** | I'm repeating back in surprise | 내일 온다고요? — tomorrow, you say? |
| **-다잖아요** | as I told you | 내일 온다잖아요 — I told you they're coming tomorrow |

- [ ] **-대요 vs -더라고요** is the distinction that separates an intermediate speaker from an advanced one. -대요 = I heard it from somewhere. -더라고요 = I saw/heard it for myself, and I'm telling you what I found.
- [ ] **-다면서요** is a confirmation, and it carries a mild challenge: *I heard X — is that right?*

> **Module completion gate (8.2).** Given ten situations, you choose between -대요, -더라고요, -다면서요, and -다고요?, with the reason stated.

## 8.3 — Quoting correctly at length

**Objective.** Report a two-minute conversation accurately, which is a different skill from quoting one sentence.

### Module 8.3.1 — The structure of a report

| Stage | Korean |
|---|---|
| Attribute | 어제 민수 씨랑 얘기했는데 |
| Set the scene | 민수 씨가 그러는데 |
| Quote 1 | 내일 회의는 취소됐대요 |
| Quote 2 | 대신 다음 주에 하자고 했어요 |
| Your stance | 그래서 제가 확인해 보겠다고 했어요 |
| Close | 아무튼 그렇게 정리됐어요 |

### Module 8.3.2 — The attribution verbs

- [ ] 말하다 · 이야기하다 · 전하다 · 알려 주다 · 물어보다 · 대답하다 · 주장하다 · 강조하다 · 부인하다 · 인정하다 · 약속하다
- [ ] News register: -다고 밝혔다 (announced), -다고 전했다 (reported), -다고 주장했다 (claimed), -다고 반박했다 (countered).

> **Module completion gate (8.3).** You retell a three-minute conversation in ninety seconds, with at least five quotes, using the correct quote type for each and no lost nuance.

## 8.4 — Passive I: the four short suffixes

**Objective.** The suffix system that makes Korean passive voice.

### Module 8.4.1 — The four suffixes

| Suffix | Example | Meaning |
|---|---|---|
| **-이-** | 보이다, 쓰이다, 놓이다 | to be seen, used, placed |
| **-히-** | 잡히다, 읽히다, 닫히다, 팔리다 | to be caught, read, closed, sold |
| **-리-** | 열리다, 팔리다, 물리다 | to be opened, sold, bitten |
| **-기-** | 안기다, 쫓기다, 감기다, 끊기다 | to be held, chased, wound, cut off |

### Module 8.4.2 — The pairs you must know

| Active | Passive | Meaning |
|---|---|---|
| 보다 | 보이다 | to be seen |
| 잡다 | 잡히다 | to be caught |
| 팔다 | 팔리다 | to be sold |
| 열다 | 열리다 | to be opened |
| 닫다 | 닫히다 | to be closed |
| 쓰다 | 쓰이다 | to be used, written |
| 놓다 | 놓이다 | to be placed |
| 끊다 | 끊기다 | to be cut off |
| 감다 | 감기다 | to be wound |
| 물다 | 물리다 | to be bitten |
| 쫓다 | 쫓기다 | to be chased |
| 찾다 | 찾아지다 (rare) | — |

- [ ] **The warning:** 보이다 does not mean "is seen" in most sentences. `그 책이 잘 보여요` = the book is visible / looks good. Korean uses 보이다 far more often as *appear* than as *be seen*.
- [ ] Passive sentences in Korean almost always take **이/가**, not 을/를: `문이 열렸어요`, never 문을 열렸어요.

> **Module completion gate (8.4).** Twenty active → passive conversions, all four suffixes, with the particle changed correctly.

## 8.5 — Passive II: -아/어지다 and -게 되다

**Objective.** The two passive constructions you will actually use most.

### Module 8.5.1 — -아/어지다: becoming, changing state

| Base | Result | Meaning |
|---|---|---|
| 좋다 | 좋아지다 | to get better |
| 나쁘다 | 나빠지다 | to get worse |
| 크다 | 커지다 | to grow |
| 많다 | 많아지다 | to increase |
| 바뀌다 | — | to change (already passive) |
| 예쁘다 | 예뻐지다 | to become pretty |
| 따뜻하다 | 따뜻해지다 | to get warm |
| 없어지다 | — | to disappear |
| 생기다 | — | to arise, to appear |

- [ ] -아/어지다 is about **state change**, not about being acted upon. This is the passive-like form Korean uses constantly and English has no single equivalent for.
- [ ] `한국어가 늘었어요` = my Korean improved. `한국어가 늘어졌어요` ✗ — some verbs take -았/었 directly, not -아/어지다.

### Module 8.5.2 — -게 되다: come to be, ended up

| Korean | Meaning |
|---|---|
| 한국에 가게 됐어요 | I ended up going to Korea |
| 알게 됐어요 | I came to know |
| 하게 됐어요 | I ended up doing it |
| 이사 가게 됐어요 | I ended up moving |
| 그렇게 되었어요 | It turned out that way |

- [ ] -게 되다 describes a change of circumstance with no agent, and it is the polite way to describe something that happened *to* you. It removes responsibility: `늦게 됐어요` sounds softer than `늦었어요`.

> **Module completion gate (8.5).** Fifteen sentences using -아/어지다 and -게 되다, with the state-change versus circumstance distinction made explicit.

## 8.6 — Causative I: the suffixes

**Objective.** Make something happen to something else.

### Module 8.6.1 — The six suffixes

| Suffix | Example | Meaning |
|---|---|---|
| **-이-** | 먹이다, 죽이다, 녹이다 | to feed, kill, melt |
| **-히-** | 입히다, 읽히다, 앉히다 | to dress, make read, seat |
| **-리-** | 살리다, 울리다, 돌리다 | to save, make cry, turn |
| **-기-** | 웃기다, 씻기다, 숨기다 | to make laugh, wash (someone), hide |
| **-우-** | 재우다, 깨우다, 세우다 | to put to sleep, wake, stand up |
| **-추-** | 낮추다, 늦추다, 맞추다 | to lower, delay, fit |

### Module 8.6.2 — The pairs

| Base | Causative | Meaning |
|---|---|---|
| 먹다 | 먹이다 | to feed |
| 입다 | 입히다 | to dress someone |
| 앉다 | 앉히다 | to seat someone |
| 자다 | 재우다 | to put to sleep |
| 깨다 | 깨우다 | to wake someone |
| 죽다 | 죽이다 | to kill |
| 살다 | 살리다 | to save (a life) |
| 웃다 | 웃기다 | to make laugh |
| 울다 | 울리다 | to make cry |
| 알다 | 알리다 | to inform |
| 서다 | 세우다 | to stand something up |
| 낮다 | 낮추다 | to lower |

> **Module completion gate (8.6).** Twenty causative conversions across all six suffixes, each in a full sentence with a clear agent and patient.

## 8.7 — Causative II: -게 하다 and -도록 하다

**Objective.** The productive causative, which works on any verb.

### Module 8.7.1 — The two forms

| Form | Meaning | Example |
|---|---|---|
| **-게 하다** | make/let someone do | 아이를 웃게 했어요 — I made the child laugh |
| **-도록 하다** | see to it that; instruct | 내일까지 끝내도록 하세요 — see that it's finished by tomorrow |
| **-게 만들다** | make (stronger, emotional) | 사람을 화나게 만들었어요 |

- [ ] -게 하다 is neutral: it can mean *make* or *let*, depending on context. `가게 했어요` = I let him go / I made him go. Add context.
- [ ] -도록 하다 is the instruction form, and it is what you use in a workplace or a written notice.

### Module 8.7.2 — When to use which

| Situation | Form |
|---|---|
| Physical action on a person or animal | suffix causative (먹이다, 재우다) |
| Emotional or psychological | -게 하다 (웃게 하다, 슬프게 하다) |
| Instruction, formal | -도록 하다 |
| Anything not covered by a suffix | -게 하다 |

> **Module completion gate (8.7).** Ten sentences using -게 하다 and -도록 하다, with a justification for choosing them over a suffix form.

## 8.8 — The ambiguity: same suffix, two directions

**Objective.** The trap that catches every advanced learner — suffixes that can be passive *or* causative.

### Module 8.8.1 — The ambiguous set

| Form | Passive reading | Causative reading |
|---|---|---|
| **보이다** | to be seen, to be visible | to show |
| **들리다** | to be heard | to make hear (rare) |
| **알리다** | — | to inform |
| **감기다** | to be wound | to wind something |
| **끊기다** | to be cut off | to cut (causative reading rare) |
| **붙이다** | — | to attach |
| **붙다** | to stick, to adhere | — |
| **씌우다** | to be covered | to cover something with |
| **마르다 / 말리다** | to dry (itself) | to dry something |

### Module 8.8.2 — How you disambiguate

1. **The particle.** 이/가 subject → usually passive; 을/를 object present → usually causative.
2. **The agent.** If there is an explicit agent with 에게/한테, causative is more likely.
3. **Plausibility.** `옷이 감겼어요` (the clothes got wound) vs `실을 감겼어요` (I wound the thread).

- [ ] These forms are memorised as *words*, not derived. Build a list, learn the pairs, and let usage settle it.

> **Module completion gate (8.8).** Given fifteen sentences, you identify each as passive or causative, and state which of the three disambiguation cues decided it.

## 8.9 — Why Korean prefers the active

**Objective.** Avoid the most recognisable translationese.

### Module 8.9.1 — The frequency difference

- [ ] Korean uses the passive far less than English. Where English says "the window was broken by the storm", Korean says `폭풍 때문에 창문이 깨졌어요` — the storm caused the window to break.
- [ ] Where English says "I was told that…", Korean says `___라고 들었어요` — I heard that…
- [ ] Where English says "it is believed that…", Korean says `___라고 합니다` — they say…

### Module 8.9.2 — The four replacements for the passive

| Instead of passive | Korean uses |
|---|---|
| be told | 듣다, -라고 들었다 |
| be given | 받다 |
| be shown | 보여 주다 |
| be sent | 받다 / 보내오다 |
| it is said | -다고 한다, -다고 합니다 |

> **Module completion gate (8.9).** You rewrite ten passive English sentences into natural Korean, and none of them uses a mechanical suffix passive.

## 8.10 — Reading the voice in text

**Objective.** Recognise passive, causative, and hearsay in news and literature, where they carry evidential meaning.

### Module 8.10.1 — The news register

| Form | Function in news |
|---|---|
| -다고 밝혔다 | official announcement |
| -다고 전했다 | reported by a source |
| -다고 주장했다 | claimed (distancing) |
| -ㄴ 것으로 드러났다 | it was revealed that |
| -ㄴ 것으로 보인다 | it appears that |
| -기로 했다 | it was decided to |
| -게 됐다 | it has come about that |

- [ ] These forms are **evidential markers**: they tell the reader how the paper knows. Getting them wrong is a factual error, not a stylistic one.
- [ ] `주장했다` versus `밝혔다` is the difference between "claims" and "announced" — a newspaper choosing one is making an editorial statement.

> **Module completion gate (8.10).** You read a 400-word news brief and list five evidential markers, saying what each implies about the source.

# LEVEL 9 — REGISTER AND NUANCE

> **Goal.** Say the same thing four different ways, and know which one a situation demands. By the end of this level you move between 해요체, 합니다체, 해체, and 반말 without a slip, and you can hear the difference between a neutral statement, a reproach, a discovery, and a joke — which in Korean is carried almost entirely by the final ending.

## Level dashboard

| Item | Details |
|---|---|
| **Level** | 9 — Register and Nuance |
| **Difficulty** | Upper-intermediate → advanced |
| **Suggested duration** | 4–5 weeks |
| **Study commitment** | 2–3 hours per day |
| **Core tools** | Recorder, two tutors (one for formal role-play), drama with subtitles off, a workplace dialogue corpus |
| **Main project** | **`register-lab`** — one piece of content, four registers |
| **Final outcome** | Four registers controlled; twelve nuance endings read correctly; honorifics used without over- or under-honorifying. |

**Prerequisites.** Level 8 complete.

> **Why this level matters more than it sounds.** You can have perfect grammar and still be *wrong* here, because register errors are social errors, not linguistic ones. A 반말 slip to a stranger is heard as arrogance. Over-honorification of yourself is heard as mockery. Neither is corrected politely, and neither is forgotten.

---

## 9.1 — The full register system

**Objective.** See all six registers, not the two you have been using.

### Module 9.1.1 — The six

| Register | Ending | Use | Example |
|---|---|---|---|
| **합니다체** (formal polite) | -ㅂ니다/습니다 | presentations, news, first meetings, military, service | 갑니다 |
| **해요체** (informal polite) | -아/어요 | the daily default | 가요 |
| **해체 / 반말** (intimate) | -아/어 | close friends, family, children | 가 |
| **해라체** (plain written) | -ㄴ다/다 | diaries, books, newspapers, reports | 간다 |
| **하게체** (familiar, archaic) | -게/네 | older-generation address to a junior, historical drama | 가게 |
| **하오체** (semi-formal, archaic) | -오/소 | historical drama, ceremonial | 가오 |

- [ ] You need to *produce* three: 합니다체, 해요체, 해체/반말.
- [ ] You need to *read* all six, because novels, dramas, and documents use registers nobody speaks.

### Module 9.1.2 — The same sentence in four registers

| Register | Korean |
|---|---|
| 합니다체 | 내일 회사에 갑니다. |
| 해요체 | 내일 회사에 가요. |
| 해체 | 내일 회사에 가. |
| 해라체 | 내일 회사에 간다. |

- [ ] Nothing changes except the ending. That is the whole difficulty: the ending carries the social relationship.

> **Module completion gate (9.1).** Ten sentences rendered in all four registers, spoken, with no cross-contamination between them.

## 9.2 — Choosing the register

**Objective.** The four axes, applied in real time.

### Module 9.2.1 — The axes

| Axis | Question | Effect |
|---|---|---|
| **Age** | older, same, younger? | the primary driver in Korean |
| **Hierarchy** | senior, junior, peer? | overrides age at work |
| **Intimacy** | how well do you know them? | gates 반말 |
| **Setting** | public, private, written? | gates 합니다체 and 해라체 |

### Module 9.2.2 — The decision table

| Situation | Register | Address |
|---|---|---|
| Stranger, any age | 해요체 | — |
| Client, customer | 합니다체 | 고객님 |
| Colleague, older | 해요체 | ___ 님 / 선배님 |
| Colleague, younger, close | 반말 | 이름 |
| Boss, formal meeting | 합니다체 | 부장님 |
| Boss, corridor | 해요체 | 부장님 |
| Friend, same age | 반말 | 이름 / 닉네임 |
| Professor | 합니다체 | 교수님 |
| Child | 반말 | 이름 |

- [ ] **The corridor rule:** the same person takes 합니다체 in a meeting and 해요체 in a corridor. Register tracks setting as well as relationship.
- [ ] **The stranger rule:** never 반말 with a stranger of any age, including a child you do not know.

> **Module completion gate (9.2).** Twenty scenarios, each with the correct register and address term, in under five minutes.

## 9.3 — 반말: acquiring it properly

**Objective.** The register you cannot take, only receive.

### Module 9.3.1 — The protocol

| Stage | What happens |
|---|---|
| 1 | You use 해요체 with everyone, always |
| 2 | The other person says `말 놓으세요` / `우리 말 놓을까요?` / `편하게 하세요` |
| 3 | You switch — **but only after one more exchange of 해요체**, as a courtesy |
| 4 | If they are older, you still use honorifics within 반말: `형, 밥 먹었어?` |

- [ ] Being invited is not the same as being required. With someone much older, stay in 해요체 even if invited — the offer is politeness, not instruction.
- [ ] You never initiate the switch with someone older. Ever.

### Module 9.3.2 — 반말 with honorifics

This is the combination learners miss: 반말 grammar with honorific vocabulary.

| 해요체 | 반말 + honorific |
|---|---|
| 선생님, 드셨어요? | 선생님, 드셨어? |
| 어머니, 주무셨어요? | 엄마, 주무셨어? |
| 할머니, 어디 가세요? | 할머니, 어디 가? |

- [ ] 반말 refers to the *ending*, not to disrespect. Dropping the honorific vocabulary at the same time is the actual error.

> **Module completion gate (9.3).** You simulate the full switch: five exchanges in 해요체, the invitation, then five in 반말 with honorific vocabulary retained.

## 9.4 — Code-switching mid-conversation

**Objective.** Change register when the situation changes, without a stumble.

### Module 9.4.1 — The switch triggers

| Trigger | Example |
|---|---|
| A third person joins | a boss enters the room mid-conversation |
| The topic becomes serious | small talk becomes a complaint |
| The medium changes | in person → on the phone |
| The relationship is redefined | a colleague becomes a client |
| Apologising formally | you drop to 합니다체 to show seriousness |

### Module 9.4.2 — The switch phrases

- [ ] `죄송합니다만` — sorry, but (the formal reset)
- [ ] `실례지만` — excuse me (formal opener to a stranger)
- [ ] `그런데요` — by the way (soft return to 해요체)
- [ ] `편하게 말씀하셔도 됩니다` — you may speak casually to me (you grant it to someone younger)

> **Module completion gate (9.4).** A role-play where a third party enters mid-conversation and you switch register within two sentences, twice.

## 9.5 — Nuance endings I: the discovery set

**Objective.** The endings that carry attitude rather than information.

### Module 9.5.1 — The table

| Ending | Function | Example | Translation |
|---|---|---|---|
| **-네요** | mild surprise, soft realisation | 맛있네요! | oh, it's good! |
| **-군요 / -구나** | realisation, "I see" | 그렇군요 | I see, so that's how it is |
| **-더라** | I observed it myself | 비가 오더라 | it was raining (I saw) |
| **-지** | confirming shared knowledge | 그렇지? | right? |
| **-잖아요** | as I told you, reminder | 내가 말했잖아요 | I told you |
| **-는데요** | background, or gentle objection | 저는 잘 모르는데요 | well, I wouldn't know |
| **-거든요** | explaining, mildly defensive | 지금 바쁘거든요 | because I'm busy, you see |
| **-기는요** | dismissing a compliment | 잘하긴요 | good? not really |
| **-다면서요** | confirming hearsay | 간다면서요? | I hear you're going? |
| **-던데요** | I remember it being, with contrast | 어제는 춥던데요 | yesterday it was cold (though) |

### Module 9.5.2 — The four that carry the most social weight

- [ ] **-네요** is the politeness of noticing. Saying `맛있네요` instead of `맛있어요` makes you gracious.
- [ ] **-잖아요** is a reproach dressed as a reminder. Use it with people you know; it is confrontational with strangers.
- [ ] **-거든요** ends a topic. It says *this is my reason, and I am not inviting discussion*.
- [ ] **-기는요** is the correct response to a compliment, and refusing it too firmly is its own error.

> **Module completion gate (9.5).** Ten situations, ten endings, each chosen for its social function rather than its translation.

## 9.6 — Nuance endings II: stance and evaluation

**Objective.** The endings that express what you think of what you are saying.

### Module 9.6.1 — The evaluation set

| Ending | Stance | Example |
|---|---|---|
| **-ㄹ 만하다** | worth doing | 먹을 만해요 |
| **-기 마련이다** | inevitably | 실수하기 마련이에요 |
| **-ㄹ 뻔했다** | almost happened | 넘어질 뻔했어요 |
| **-ㄹ 리가 없다** | impossible | 그럴 리가 없어요 |
| **-ㄹ 텐데** | supposition + softener | 바쁠 텐데 괜찮아요? |
| **-ㄹ걸요** | I suppose, mild | 내일 올걸요 |
| **-더라고요** | I found that | 생각보다 비싸더라고요 |
| **-다 보니** | as I did it, I found | 하다 보니 재미있어요 |
| **-다 보면** | if you keep doing it | 하다 보면 늘어요 |
| **-게 마련이다** | it is in the nature of things | 젊으면 그렇게 마련이에요 |

### Module 9.6.2 — The two most useful

- [ ] **-다 보면** for encouragement: `연습하다 보면 늘어요` — you'll improve if you keep practising.
- [ ] **-ㄹ 텐데** for a considerate request: `바쁠 텐데 죄송해요` — I know you're probably busy, sorry.

> **Module completion gate (9.6).** Ten sentences using four different stance endings, each with the stance named aloud.

## 9.7 — Honorifics at mastery

**Objective.** The system, without the two errors that mark a learner.

### Module 9.7.1 — The three axes, revisited

| Axis | Mechanism | Error to avoid |
|---|---|---|
| **Subject honour** | -시-, 께서, honorific vocabulary | forgetting -시- for a respected subject |
| **Object honour** | 드리다, 뵙다, 여쭙다, 모시다 | using 주다/보다/묻다 to a superior |
| **Hearer honour** | the register | register slip mid-sentence |

### Module 9.7.2 — The two errors

**Error 1 — over-honorifying yourself.**

- [ ] `저께서 하겠습니다` ✗ — you never honour your own subject with 께서.
- [ ] `제가 하겠습니다` ✓
- [ ] Humble verbs lower *you*: 드리다, 뵙다, 여쭙다, 모시다.

**Error 2 — under-honorifying the subject while being polite to the hearer.**

- [ ] `선생님이 밥을 먹어요` ✗ — polite to you, but the teacher is not honoured.
- [ ] `선생님께서 진지를 드세요` ✓

### Module 9.7.3 — The honorific vocabulary table

| Plain | Honorific (subject) | Humble (self) |
|---|---|---|
| 먹다 | 드시다 | — |
| 있다 | 계시다 | — |
| 자다 | 주무시다 | — |
| 말하다 | 말씀하시다 | 말씀드리다 |
| 주다 | — | 드리다 |
| 보다 | — | 뵙다 |
| 묻다 | — | 여쭙다 |
| 데리고 가다 | — | 모시고 가다 |
| 이름 | 성함 | 저 |
| 나이 | 연세 | — |
| 집 | 댁 | — |
| 밥 | 진지 | — |

> **Module completion gate (9.7).** Ten sentences converted to full honorific form, using all three axes, with no over-honorification of the self.

## 9.8 — Reading tone: what is not said

**Objective.** Korean conveys a great deal by omission. This is 눈치 — social perception — expressed as a reading skill.

### Module 9.8.1 — The indirect refusals

| What is said | What it means |
|---|---|
| 생각해 볼게요 | probably no |
| 좀 어려울 것 같아요 | no |
| 다음에 하죠 | no |
| 긍정적으로 검토해 보겠습니다 | no, but politely |
| 시간이 안 될 것 같아요 | no |
| 괜찮은데요… (with a pause) | no |

- [ ] A Korean no is rarely the word 아니요. It is a delay, a difficulty, or a deferral. Learning to hear it is a listening skill as much as a cultural one.

### Module 9.8.2 — Sarcasm and reproach

| Form | Effect |
|---|---|
| -다니요? | disbelief, mild outrage |
| -기는요 (sarcastic tone) | dismissive |
| 참 잘한다 | said flatly: sarcastic |
| 그렇겠네요 (flat tone) | "sure it is" |
| -시네요 (to a peer) | mock-honorific, teasing |

> **Module completion gate (9.8).** Given ten indirect refusals, you state what each means, and which you would use with a boss versus a friend.

## 9.10 — Slang, swearing, and what not to say

**Objective.** Recognition, not production. Using slang wrong is worse than not using it.

### Module 9.10.1 — The recognition list

| Korean | Register | Meaning |
|---|---|---|
| 대박 | slang | amazing |
| 헐 | slang | whoa |
| 짜증나 | casual | annoying |
| 열받아 | casual | furious |
| 미쳤다 | casual | crazy (positive or negative) |
| 존맛 | slang | really tasty |
| 갑분싸 | slang | sudden awkward silence |
| 눈치 없다 | idiomatic | socially oblivious |
| 답답하다 | standard | frustrating, stifling |
| 억울하다 | standard | unfairly treated |

### Module 9.10.2 — The rule

- [ ] **Understand everything; produce almost nothing.** Slang dates fast, and a foreigner using 2020s slang in 2030 sounds worse than a foreigner speaking plainly.
- [ ] Swearing: learn to recognise it so you are not caught off guard. Do not produce it.
- [ ] The one exception: `대박` and `헐` are safe in casual company and will make people laugh.

> **Module completion gate (9.10).** You identify ten slang expressions from a drama clip, and state which register each belongs to.

# PHASE 3 CAPSTONE — THE PANEL

> **The brief.** Sit on a three-person panel, in Korean, for thirty minutes. Deliver a five-minute opening statement on an assigned topic, take questions, disagree with someone politely, and summarise the discussion at the end — all in the correct register for a semi-formal setting.

## A. Functional requirements

1. **The opening statement.** Five minutes, structured with the five-part skeleton from 7.6, in 합니다체.
2. **The Q&A.** Ten minutes, including one hostile question and one you cannot answer.
3. **The disagreement.** Disagree with another panellist twice, using two different concession patterns, without dropping the register.
4. **The summary.** Three minutes at the end, summarising the panel's positions — including one you disagree with, reported fairly using quoted speech.
5. **The register log.** Every register switch, with the trigger.
6. **The recording and transcript.** Full thirty minutes, with the transcript annotated for structure.
7. **The reflection.** Written in Korean, 200 words, on what you avoided saying.
